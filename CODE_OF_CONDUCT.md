# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful and welcoming; no harassment, insults, sexualised language or imagery, doxxing or
publishing others' private information; give and accept constructive feedback gracefully.

**Scope:** all project spaces (issues, pull requests, discussions) and public spaces where you represent the project.

**Enforcement:** report unacceptable behaviour privately to the maintainers through GitHub (open a [private security advisory](https://github.com/stevenguyenbt/mega-shot/security/advisories/new) marked "Code of conduct", or contact @stevenguyenbt).
Reports are reviewed promptly and confidentially. Maintainers may remove comments, commits or contributions and
temporarily or permanently ban contributors, following the Contributor Covenant enforcement guidelines
(correction → warning → temporary ban → permanent ban).
